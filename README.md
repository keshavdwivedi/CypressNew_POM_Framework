An example project demonstrating automated UI tests using Typescript-based end-to-end testing framework Cypress with Page Object Model pattern.

Application Under Test
We are using Demo E-commerce as the Application Under Test.

URL : https://automationexercise.com/
Installation
Install the dependencies and devDependencies to run the test.

Clone this repo on your local machine
Navigate to project's directory on terminal and run the following commands:
npm install
Execute Tests
Run the following command in Terminal to execute tests in Headless mode:

npm run test
Run the following command in Terminal to open Cypress Test Runner:

npm run cy:open
Test Report
You can find the Mochawesome report in the following directory of the Project.

\cypress\reports\mochareports
Open 'index.html' file to view the report.
